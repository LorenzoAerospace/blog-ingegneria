Collega GitHub

Serve un token personale per pubblicare dal pannello. Resta solo nel tuo browser.

  1. Apri la pagina per creare il token ↗ (si apre con nome, durata di 90 giorni e permesso Contents: Read and write già impostati).
  2. In "Repository access" scegli Only select repositories e seleziona solo il tuo blog.
  3. Genera il token, copialo e incollalo qui sotto.

Alla scadenza ne crei uno nuovo. Puoi revocarlo in qualsiasi momento da github.com/settings/personal-access-tokens.
